## ประเภทของสัญญา
1. สัญญาณต่อเนื่องเชิงเวลา (Continuous-time Signal) vs.
สัญญาณไม่ต่อเนื่องเชิงเวลา (Discrete-time Signal)
2. สัญญาณคู่ (Even signal) และสัญญาณคี่ (Odd signal)
3. สัญญาณคาบ (Periodic Signal)
และสัญญาณไม่เป็นคาบ (Non Periodic Signal)
4. สัญญาณพลังงาน (Energy Signal) และสัญญาณกำลัง (Power Signal)
5. สัญญาณที่กำหนดค่าได้ (Deterministic Signal)
และสัญญาณสุ่ม (Random Signal)

## รูปแบบของ สัญญาณคู่ (Even signal) และสัญญาณคี่ (Odd signal)

![[Pasted image 20261118092443.png]]

Even Signal มีลักษณะ Symmetry if ต่อเนื่อง x(-t) = -x(t):
else if ไม่ต่อเนื่อง x(-n) = -x(n)

![[Pasted image 20261118092824.png]]

Odd Signal มีลักษณะ Anti-symmetry if ต่อเนื่อง x(-t) = -x(t):
else if ไม่ต่อเนื่อง x(-n) = -x(n)
